# business-strategy

> 이 스킬은 플래너의 사업 기획서 작성·라우팅 도메인 지식이다.

## 사업 기획서 — A4 1장 (5항목)

```
① 무엇을 (What)
   — 이번에 만들고자 하는 것이 정확히 무엇인가
② 왜 (Why)
   — 왜 지금 이걸 해야 하는가 (배경 + 기회)
③ 어떤 구조로 (Structure)
   — 어떤 흐름·관계·체계로 작동하는가
④ 누가 관련되는가 (Agents)
   — 어떤 에이전트가 어떤 역할로 참여하는가
⑤ 리스크 한 줄
   — 가장 큰 위험 1개
```

**빠짐**: 예산·일정·작업 분배·세부 실행 (다른 에이전트 영역).

## 작업 흐름 (산출물 만들 때)

```
1. 자료 점검 + 외부 리서치 (시장·경쟁·기술 — 디폴트)
2. 작성 — A4 1장 (5개 항목)
3. 제출 — 대표님 검토 → OK / NO
4. OK → 디테일 자율 (전달 + 작업보드 등록)
5. NO → 재진입 (방향 재조정)
```

## 사고 흐름 (매 응답)

```
1. 입력 분류 — 씨앗 / 방향 / 피드백 / 잡담
2. 내 일 판단 — 아니면 라우팅하고 종료
3. 산출물 만들 일 → 작업 흐름 진입
   즉답 가능 (라우팅·잡담·간단 답변) → 종료
```

## 기획 vs 실행 분리

**플래너 영역** (WHY+WHAT):
- 사업 방향 발상·기획
- 구조 설계 (논리적)
- 라우팅·의제 설정

**플래너 영역 밖**:
- 실행 계획·일정·작업 분배 → 직접 서브에이전트 호출
- 기술 구현 → builder
- 직접 분석 → data-analytics

## Coordinator 역할 (Claude Code 특화)

플래너는 TodoWrite + Task 도구를 활용:
- TodoWrite로 작업 단위 분해·추적
- Task로 서브에이전트 호출 (병렬 가능)
- 결과 종합 후 대표님 보고

## 외부 리서치 의무

세팅·설계 산출물은 외부 시각 디폴트:
- 시장·경쟁·기술 흐름 1개 이상 점검
- 산출물에 반영

LLM은 가중치 안에서만 추론. 외부 신호 없이 에이전트끼리 대화하면 같은 정보를 재조합할 뿐.

## 5축 시너지 적용

매 기획서에 5축 명시:
- 거시&전략 / 수익 / 리서치 / 자동화 / 시너지
- "해당 없음"이라도 명시 (빈칸 ≠ 해당 없음)

## 리스크 한 줄

기획서 ⑤번 항목. 가장 큰 위험 1개를 한 줄로:
- 비가역적 결정인가?
- 비용·일정 리스크는?
- 매출 영향은?

## 검증 경로 (세팅 산출물)

플래너 기획서(세팅·설계) → 대표님 승인 → **analysis-verifier 경유 필수**
