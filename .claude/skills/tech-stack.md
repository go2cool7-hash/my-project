# tech-stack

> 이 스킬은 기술 선택 기준 도메인 지식이다.

## 자비스 기술 스택 (Stage 1)

```
에이전트 실행: Claude Code (서브에이전트 + 스킬 + 훅 + MCP)
데이터: Notion (MCP 연동)
스크립트: Python
자동화: 수동 → Stage 2에서 Make.com / n8n
알림: 텔레그램 (예정)
재고: Cello (CSV 동기화)
```

## Stage 로드맵

| Stage | 시기 | 특징 |
|---|---|---|
| Stage 1 (현재) | - | 대표님 수동 중계. Claude Code + Notion 기반 |
| Stage 2 | M3~4 | Make.com / n8n 워크플로우. Claude API 통합 |
| Stage 3 | M5~7 | 독립 서버 + MCP 확장 + 멀티 테넌트 |
| Stage 4 | M8~ | 자비스 코어. 자율 운영. North Star |

## 도구 선택 규칙

```
단순+빠름 → Make.com (워크플로우 GUI)
복잡+셀프호스팅 → n8n (오픈소스 워크플로우)
핵심 코어+완전 제어 → Python
기존 80% 가능 → 기존 도구 우선

새 도구 도입: 기존 도구로 80% 불가할 때만
평가 기준: ① 문제 해결 ② 비용 ③ 유지보수
```

## 비용 가이드 (월 예산)

```
Stage 1~2 기준: 월 30~40만원

도구 도입 승인:
- 월 5만원 미만, 예산 내 → 디렉터 보고 후 진행
- 월 5만원 이상 또는 예산 초과 → 대표님 승인 (비용 + ROI + 대안)
```

## ROI 산출

```
ROI = (절약 시간 × 시간당 가치) / 운영 비용

ROI < 1: 경고 → 대안 제시
ROI 양수 확인 후 진행
```

모든 봇/파이프라인에 필수:
- 자동 재시도 (3회 + 지수 백오프)
- 실패 시 알림 (텔레그램·이메일)
- 수동 대체 경로
- 모니터링 (상태, 에러 빈도, 성능)

## SaaS 전환 판단 (SHARED-1)

```

  SaaS 확장 가능 → 파라미터화 + 멀티 테넌트 구조
```
