# analytics-methods

> 이 스킬은 분석 방법론과 전략 해석 도메인 지식이다.

## 분석 파이프라인 (Phase B)

```
B.1 데이터 상태 진단 (기간, 양, 품질, 판단 가능 수준)
B.2 핵심 지표 계산 (선행+후행 동시)
B.2.5 DB 교차 정합성 점검 (트리거 시)
B.3 원인 진단 (PB-1) — 증상이 아니라 원인
B.4 방향 판단 + 전략 해석 (PB-8) ⭐
B.5 비즈니스 맥락 렌즈
B.6 액션 설계 + 2차 결과 예측 (PB-2)
```

## B.3 원인 진단 체크리스트

지표 뒤의 원인을 찾는다. 다음 6개 카테고리 점검:

- □ 외부 요인 (시즌, 경쟁, 플랫폼 변화)
- □ 내부 요인 (상품력, 가격, 재고)
- □ 광고 요인 (키워드, 타겟, 크리에이티브)
- □ 마케팅 요인 (캠페인, 프로모션)
- □ 운영 요인 (배송, CS, 리뷰)
- □ 데이터 자체 문제 (추적 오류, 결측)

원인 특정 → 명시 / 추정만 → `[추정]` 라벨 + 근거 / 불명 → "파악 위해 X 필요"

## B.4 전략 해석 (PB-8) — 가장 중요

분석의 끝은 "그래서 뭘 해야 하는가". 다음 3개 질문에 답:

- **Q1**: 이 숫자가 사업 방향에 어떤 의미인가?
  - 통과 기준: "좋다/나쁘다"가 아니라 "왜 좋고, 어디가 위험한가" 명시
  - 나쁜 예: "매출 상승 추세입니다" (그래서?)

- **Q2**: 지금 행동하지 않으면 어떻게 되는가?
  - 통과 기준: 비행동 결과 + 시간 범위 명시
  - 나쁜 예: "리스크가 있을 수 있습니다" (언제? 얼마나?)

- **Q3**: 어떤 에이전트가 어떤 행동을 해야 하는가?
  - 통과 기준: 구체적 에이전트명 + 액션 1개+
  - 나쁜 예: "대응이 필요합니다" (누가? 뭘?)

판별: "이 리포트를 읽은 대표님이 '그래서 뭘 해야 하는데?'라고 물었을 때 답이 있는가?"

## B.6 액션 설계 — 2차 결과 예측 필수 (PB-2)

각 제안에 5개 필수 항목:

- ① 액션 (구체적으로 뭘 할 것인가)
- ② 근거 (어떤 데이터에 기반)
- ③ 기대 효과 (숫자로)
- ④ 리스크/부작용 (구체적으로)
- ⑤ 대안 (메인 제안 실패 시)

**극단적 제안 차단 (PB-4)**:
"전부 중지", "예산 3배" 같은 제안은 극단적 근거(30일 전환 0건 등) 있을 때만 허용. 아니면 단계적 액션으로 다운그레이드.

## DB 교차 정합성 점검 (B.2.5)

**계층 1 — 작업 시점 교차 점검**:
- 트리거: DB 스키마 변경, 대량 데이터 입력/수정, 새 DB 생성
- 점검: 키/필드 참조 / 참조 관계 / 형식·단위 일치

**계층 2 — 정기 교차 감사**:
- 주기: DB 관련 작업 5건 누적 또는 대표님 요청 시
- 범위: 운영 중인 전체 DB 상호 참조 관계

## A/B 테스트 원칙

- 신뢰구간 95% (100번 실험하면 95번은 이 범위)
- 최소 표본 크기 충족 필수
- 결과 애매 시 결론 내지 않음 → 추가 실험 제안 → 잠정 경향만
- "유의미인데 실행 후 효과 없음" → 설계 결함(표본·기간·세그먼트) or 외부 변수 미통제

## 분석 진단 엔진 (Phase G) — 원인 레벨

- L5 분석 실행 — 계산 오류, 비교 기준 착오, 어트리뷰션 모델 오류, 확증 편향, 표본 부족 확정 판단, 전략 해석 부재
- L4 입력 품질 — 커머스옵스/마케팅/상품MD 데이터 부정확
- L3 측정 구조 — KPI 정의 부적절, 채널 측정 기준 불통일, A/B 설계 결함
- L2 전략/방향 — KPI 목표 비현실적, 분석 우선순위 불일치
- L1 외부 — 플랫폼 트래킹 정책, API 변경, 시즌 변동

**원칙**: 분석가 자신의 문제(L5)를 외부 원인(L1)으로 돌리지 않는다.

## 정정 보고

이전 분석 수정 시 → 수신 에이전트에게 즉시 정정 보고.

형식: `[정정] 기존 분석 X → 수정 Y. 변경 사유: Z. 의사결정 영향: W`

## 보고 형태

- **일간**: 채널별 매출 → 광고 성과 → 이상치 알림
- **주간**: KPI 스코어카드 → 선행+후행 트렌드 → 방향 신호 → 전략 해석 → 인사이트
- **월간**: 월간 성과 종합 → 목표 대비 → 채널별 심층 → 사업 건강도 → 전략 해석 → 다음 달 전망
