# kpi-framework

> 이 스킬은 KPI 프레임워크와 사업 건강도 측정 도메인 지식이다.

## 채널별 KPI 역할

| 채널 | KPI 우선순위 |
|---|---|
| 오늘의집 | 매출 + ROAS (메인 매출) |
| 자사몰 | LTV (브랜드) |
| 스마트스토어 | 자연유입 + SEO 노출 |
| 29CM | 객단가 + 브랜드 포지셔닝 |
| 쿠팡 | 회전율 + 가격 경쟁력 |

## 선행 지표 vs 후행 지표 (PB-6)

**후행 지표** (이미 일어난 일):
- 매출, 마진
- ROAS, CPA
- 반품률

**선행 지표** (앞으로 일어날 일):
- 유입량, 노출
- 장바구니율
- 검색 키워드 추이
- 리뷰 작성률

**원칙**: 후행만 보고 방향 판단 금지. 선행+후행 동시 확인.

## 사업 건강도 스코어카드 (월간)

**쇼핑몰**:
- 매출 (전월 대비 / 목표 대비)
- 마진 (실제 vs 계획)
- 채널 다변화 (한 채널 의존도 80% 이하?)
- 신상 비율 (전체 매출 중)
- 재구매율

**종합 등급**: 견고함 / 보통 / 취약함 / 위태로움

## 데이터 충분성 판단 (PB-5)

| 데이터 기간 | 판단 가능 수준 |
|---|---|
| 1일 | 현황 스냅샷만 (판단 금지) |
| 3일 | 경향 파악 ([잠정] 라벨, 확정 판단 금지) |
| 7일 | 캠페인/상품별 판단 가능 |
| 30일 | 전략적 의사결정 가능 |

표본 부족 시: `[잠정]` 라벨 + 신뢰도 하향 + 필요 데이터 명시.

## 조기 경보 트리거 (Phase F)

다음 조건 충족 시 정기 리포트 무관 즉시 발동:

- 선행 지표 3개 이상 동시 하락
- 핵심 KPI 정상 범위 2주 연속 이탈
- 채널 의존도 80% 이상 집중
- SaaS 지표가 목표 궤적에서 30% 이상 이탈

발동 시: `⚠️ 방향 전환 신호 → 감지 근거 → 예상 궤적 → 전략 해석 → 제안 액션`

## SaaS 지표 (Phase 2+)

- MRR (월간 반복 매출)
- Churn (이탈률)
- CAC / LTV
- 온보딩 완료율
- 핵심 기능 사용률

## 융합 지표

- 자비스 시스템 활용률
- 자동화 절감 시간
- 쇼핑몰→SaaS 크로스 기여도

## 비교 기준 필수 (R-04)

모든 숫자에 비교 기준 병기:
- 전주 대비
- 전월 대비
- 목표 대비

비교 기준 없는 숫자 = 의미 없는 숫자.
