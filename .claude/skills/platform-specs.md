# platform-specs

> 이 스킬은 채널·플랫폼별 콘텐츠 규격 도메인 지식이다.

## 쇼핑 플랫폼별 콘텐츠 분화

### 오늘의집
- **이미지**: 정사각형 (800×800px+), 라이프스타일·감성 무드
- **카피**: 감성 톤, 라이프스타일 키워드
- **추가 콘텐츠**: 시공사례, 집들이, 리뷰 유도
- **구조**: 라이프스타일 이미지 + 감성 카피 + 리뷰 유도

### 29CM
- **이미지**: 에디토리얼, 프리미엄 무드
- **카피**: 스토리텔링, 브랜드 스토리
- **구조**: 에디토리얼 이미지 + 스토리텔링 카피 + 브랜드 스토리

### 쿠팡
- **이미지**: 누끼 이미지 (배경 제거)
- **카피**: 기능·스펙·가격 먼저
- **구조**: 깔끔한 레이아웃 + A+ 콘텐츠
- **예외**: 가구는 공간 연출 일부 허용

### 스마트스토어
- **이미지**: 정보 중심
- **카피**: SEO 키워드 상품명 + 검색 의도 반영
- **구조**: 블로그 연동 구조

## 영상 플랫폼별 규격

### 유튜브 롱폼
- 비율: 16:9
- 길이: 8~15분 권장
- 썸네일: 1280×720px
- 첫 30초 후킹 필수

### 유튜브 쇼츠
- 비율: 9:16
- 길이: 60초 이내
- 세로형 최적화

### 인스타 릴스
- 비율: 9:16
- 길이: 15~60초
- 음악 활용

### 인스타 피드
- 정사각형 1:1 또는 4:5
- 캡션 첫 줄 후킹

### 인스타 캐러셀
- 1:1, 최대 10장
- 첫 장 후킹 + 마지막 장 CTA

## 광고 소재 규격

### 메타(인스타그램) 광고
- 피드: 1:1
- 스토리: 9:16
- 캡션 글자수 제한

### 네이버 SA/DA
- 텍스트 광고: 글자수 제한 엄격
- 디스플레이: 다양한 사이즈

### 오늘의집 광고
- 자체 규격 준수

## 콘텐츠-채널 매칭 원칙

**금지**: 다중 플랫폼에 복사+붙여넣기 (PB-3)

**필수**: 채널 알고리즘·고객 행동·콘텐츠 형식에 맞춰 분화

| 콘텐츠 유형 | 적합 플랫폼 |
|---|---|
| 라이프스타일 무드 | 오늘의집, 29CM, 인스타 피드 |
| 기능·스펙 | 쿠팡, 스마트스토어 |
| Before/After | 유튜브 쇼츠, 인스타 릴스 |
| 튜토리얼·하우투 | 유튜브 롱폼, 블로그 |
| 트렌드·일상 | 스레드, 인스타 캐러셀 |
