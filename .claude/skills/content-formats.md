# content-formats

> 이 스킬은 콘텐츠 포맷별 제작 도메인 지식이다. 상세페이지·영상·블로그·SNS 캐러셀 규격과 구성 원칙.

## 상세페이지

### 구조 (스크롤 순서 = 설득 순서)

```
1. Above the fold (첫 화면, 3초 룰)
   - 대표 이미지
   - 한 줄 후킹 카피
   - 핵심 셀링 포인트 1개
2. 문제 제기 (PAS — Problem)
3. 솔루션 제시 (PAS — Agitation + Solution)
4. 사용 시나리오 (라이프스타일 이미지)
5. 스펙·사이즈·소재 (정확성)
6. 리뷰 유도 (사회적 증거)
7. CTA (구매 버튼)
```

### 카피 3층위

- **상품명**: SEO 키워드 포함, 검색에 걸리면서 구매 유도
- **한 줄 소개**: 핵심 셀링 포인트
- **상세 설명**: Features → Benefits 전환

### 치알디니 설득 원칙 (상세페이지에 최소 2개 의도적 배치)

- 사회적 증거 (리뷰, 베스트셀러)
- 희소성 (재고, 한정)
- 권위 (전문가 추천)
- 일관성 (브랜드 톤)
- 호감 (라이프스타일 공감)
- 상호성 (사은품, 무료 배송)

## 유튜브 영상

### 롱폼 구성

```
오프닝 (첫 30초 후킹) — Before/After, 충격 사실, 질문
본론 (5~10분)
CTA (구매 링크, 구독 유도)
```

### 첫 30초 후킹 (OB-VIDEO-01)

- Before/After 비교
- 충격적인 사실 ("주방 정리 못 하는 사람의 80%가 이걸 모릅니다")
- 질문 ("이 수납함 하나로 욕실이 호텔처럼 되는데, 어떻게요?")

### 썸네일 컨셉

- 강한 대비 (Before/After)
- 큰 텍스트 (모바일 시청 고려)
- 얼굴 표정 (있을 때)

### 제목·태그 최적화

- 키워드 1순위 + 후킹 키워드
- 예: "주방 정리 꿀팁" (월 검색 12,000) + "5분 완성"

### 크로스 플랫폼 재가공 (OB-VIDEO-02)

```
유튜브 롱폼 "주방 정리 꿀팁 5가지"
  → 쇼츠 60초 (가장 임팩트 1가지)
  → 인스타 릴스 15초 (Before/After)
  → 블로그 SEO 포스트 (상세 5가지 + 제품 링크)
  → 스레드 "3초 꿀팁" 텍스트
```

## 인스타그램

### 릴스

- 숏폼 영상 (15~60초)
- 음악·트렌드 연동
- 세로형 9:16

### 피드

- 이미지 + 캡션 + 해시태그
- 첫 줄 후킹 (캡션 더보기 클릭 유도)

### 캐러셀

- 다컷 이미지 (10장 이내)
- 스와이프 유도 설계 (첫 장 후킹 + 마지막 장 CTA)
- 해시태그 전략

## 블로그

- SEO 최적화 (키워드 자연스럽게 배치)
- 제품 정보 + 라이프스타일 콘텐츠
- 제품 링크 자연스럽게 배치
- H2/H3 구조화

## 스레드

- 짧고 임팩트 있는 텍스트
- 제품/브랜드 스토리 연결
- 대화 유도 (질문 던지기)

## 이미지 가이드

- 무드보드 필수 (텍스트만 금지)
- 촬영 가이드: 구도, 스타일링, 라이팅, 필수 컷 리스트
- 편집 가이드: 보정 방향, 합성, 플랫폼별 리사이징
- 대표 이미지·첫 3컷 품질 타협 불가
- 공간 연출 이미지 > 누끼 (쿠팡 제외)
