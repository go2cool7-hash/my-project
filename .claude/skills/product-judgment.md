# product-judgment

> 이 스킬은 상품 후보를 평가하고 판단할 때 적용하는 도메인 지식이다. PB-1~PB-9 판단 기준 + C.0 두 갈래 게이트 + 마진 시뮬레이션 + 트렌드 수명 판단을 포함한다.

## PB 판단 기준 (PB-1 ~ PB-9)

- **PB-1**: 감이 아니라 데이터. 데이터에서 기회를 읽고 돈이 되는 상품으로 전환. 데이터 부족 시에도 가설 제시. "데이터 없어서 모르겠다" 종결 금지.
- **PB-2**: 마진이 안 나오면 아무리 트렌디해도 NO. 수익성 가드레일 이탈 불가.
- **PB-3**: 트렌드 타이밍이 핵심. "좋은 상품"보다 "지금 팔리는 상품"이 우선. 트렌드 수명 판단 필수.
- **PB-4**: 기획이 잘못되면 뒷 파이프라인 전체가 헛돈다.
- **PB-5**: 모든 추천에는 순위와 근거. "다 좋아요" 분석은 분석이 아니다.
- **PB-6**: 숫자로 말하되, 숫자 뒤의 심리도 읽는다. 정량+정성 연결.
- **PB-7**: 트렌드 분석은 출발점이지 결과물이 아니다. "이 카테고리가 뜨고 있습니다"=뉴스레터. "그래서 우리가 이런 상품을 이런 컨셉으로 밀어야 합니다"까지가 산출물.
- **PB-8**: 홈리빙에서 이기는 법은 두 가지뿐:
  - ① **없는 걸 만든다** — 획기적인 상품을 기획·제안 (갈래 1)
  - ② **있는 걸 다르게 판다** — 같은 상품이라도 컨셉으로 차별화 (갈래 2)
  - "가격 경쟁"은 전략이 아니다.
- **PB-9**: 데이터가 부족하면 아이디어로 승부. 실시간 데이터 한계 인정. "데이터 부족해서 일반론밖에"=변명. "데이터는 부족하지만 시장 구조 보면 이 컨셉이 먹힙니다"=상품MD.

## 트렌드 수명 분류 (PB-3 적용)

- **마이크로 트렌드**: 3~6개월. 빠른 진입·빠른 회수.
- **매크로 트렌드**: 1년+. 안정적이지만 경쟁 격화.
- **일시적 유행**: 1~2개월. 진입 자체가 리스크.

**확산 곡선(Rogers)**: 이노베이터 → 얼리어답터 → 초기다수 → 후기다수 → 지각수용. "지금 곡선의 어디인가"로 진입 판단.

## C.0 게이트 — 두 갈래 + 공통 (필수)

기획서 작성 전 반드시 통과.

### 갈래 1 — 상품 기획: 이 시장에 없는 걸 만들자

- **Q1-A. 시장 빈틈**: 고객이 불편해하는데 해결되지 않은 포인트? 리뷰 불만 분석에서 추출.
  - 통과 기준: 구체적 불편(예: "습기로 곰팡이 핀다") 인용
- **Q2-A. 상품 아이디어**: 빈틈을 채우는 구체적 상품? 기능·디자인·가격대·타겟 명시.
  - 좋은 예: "항균 대나무 + 방습 코팅 욕실 수납함, 판매가 29,000원, 마진 55%"
- **Q3-A. 실현 경로**: OEM/ODM 가능성, 공급처, 예상 비용.

### 갈래 2 — 컨셉 설계: 있는 걸 다르게 팔자

- **Q1-B. 컨셉 아이디어**: "왜 사야 하는가"의 이유를 새로? 기존 경쟁자들이 안 쓰는 새 구매 이유.
  - 좋은 예: "같은 수납함도 '미니멀 호텔 욕실을 우리 집에' 컨셉으로 4,000원 프리미엄"
- **Q2-B. 타겟 재정의**: 기존 타겟(레드오션) → 새 타겟(블루오션).
- **Q3-B. 비주얼 방향**: 상세페이지·썸네일·광고에서 어떻게 보여야 하는가?

### 공통

- **Q4. 경쟁 차별화**: 따라 하기 어려운 이유? (AI 자동화, 속도, 데이터)
- **Q5. 승리 조건**: 이것이 거짓이면 기획이 무너진다는 핵심 전제 1개.
- **Q6. 철수 기준**: 구체적 수치 또는 기간이 포함된 철수 조건.
- **Q7. AI 우위**: 자비스가 만들어주는 구체적 경쟁 우위 (소싱 속도, 상세페이지 자동, A/B 테스트).

## 마진 시뮬레이션 (PB-2 적용)

```
계획 마진 = 판매가 − 원가 − 채널 수수료 − 물류비 − 반품률 반영

채널별 수수료 반영:
  오늘의집: 12~20%
  29CM: ~25%
  쿠팡: ~10.8%
  스마트스토어: ~5.5%

BEP 역산 = 최소 판매량 계산
ROAS 연쇄 = "이 마진에서 이 광고비면 ROAS가 얼마여야 하는가"
정산 주기: 15~45일 → 현금 흐름 영향
```

## 시장 감지 + 분석 흐름

```
B.1 트렌드 분석 (수명 + 진입 타이밍)
B.2 경쟁사 분석 (가격·리뷰·포지셔닝 + 마진 역산 + 고객 불만)
B.3 소비자 심리 (의사결정 경로 인지→관심→비교→구매→후기)
B.4 SaaS 시장 (셀러 페인포인트, 경쟁 SaaS)
```

## 좋은 예 (전체)

**[갈래 1 — 상품 기획]**
"오늘의집 '욕실 수납' 리뷰 500개 분석 결과, '습기로 곰팡이 핀다' 불만 23%로 최다. 항균·방습 소재 수납함은 시장에 거의 없음(2개뿐). → 상품 아이디어: 항균 대나무 + 방습 코팅 욕실 수납함. 타겟: '깔끔한 욕실' 키워드 월 검색 8만. OEM 견적: 개당 8,000원, 판매가 29,000원, 마진 55%."

**[갈래 2 — 컨셉 설계]**
"같은 아크릴 수납함(시장 평균가 15,000원)인데, 기존 셀러들은 '수납 정리' 키워드로만 판매 중. → 컨셉: '미니멀 호텔 욕실을 우리 집에'. 타겟 재정의: '정리 필요한 사람'(레드오션) → '인테리어 감각 있는 2030'(블루오션). 비주얼: 호텔 욕실 무드, 생활감 제거, 미니멀 톤. 이 컨셉으로 같은 상품을 19,000원에 판매(4,000원 프리미엄)."
