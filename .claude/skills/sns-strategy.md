# sns-strategy

> 이 스킬은 콘텐츠 마케팅 전략 도메인 지식이다. 유튜브 우선 + 광고+콘텐츠 양축 배합.

## 두 축 원칙

- **광고** = 유료 채널로 즉시 트래픽. 비용이 든다.
- **콘텐츠** = 유튜브·인스타·블로그·스레드로 유기 유입. 시간이 든다.
- 두 축의 **배합이 마케팅 전략의 핵심**.
- 광고만으로는 고객 획득 비용이 계속 오른다. 콘텐츠가 유기 유입을 만들어야 지속 가능.

판별: "유료 광고를 끄면 고객 유입이 0이 되는가?" → 0이면 콘텐츠 전략 부재.

## STEP 2.0 전략 판단 게이트 (6개 질문)

### 광고 전략 (Q1~Q3)

- **Q1. 경쟁 우위 채널**: 4채널 + 콘텐츠 플랫폼 중 우리가 경쟁 대비 가장 유리한 채널? 왜?
  - 차별화 축(가격/콘텐츠/리뷰/속도/감성 중 1+) 명시
- **Q2. 예산 집중 논리**: 광고 vs 콘텐츠 비율 + 채널별 배분 근거?
- **Q3. 고객 획득 비용 비교**: 채널별 CAC 추정치?

### 콘텐츠 마케팅 전략 (Q4~Q6)

- **Q4. 콘텐츠 채널 우선순위**: 유튜브·인스타·블로그·스레드 중 집중 채널? ⭐ 유튜브 우선.
  - 검색량, 경쟁 현황, 성장 가능성 명시
- **Q5. 콘텐츠 방향 설계**: 크리에이티브에 요청할 주제·형식·빈도·타겟?
  - 좋은 예: "유튜브 주간 2개 숏폼 — 주제: 주방 정리 꿀팁, 타겟: 2030 자취 여성, 이유: 월 검색 12,000"
- **Q6. 다음 수**: 이 캠페인/콘텐츠가 끝나면 다음에 뭘?

## 콘텐츠 전략 ↔ 크리에이티브 실행 분업

- **마케팅** = "어떤 플랫폼에, 어떤 주제로, 어떤 빈도로, 왜" (전략)
- **크리에이티브** = "어떻게 만들 것인가" (기획·제작)

이 분업이 깨지면:
- 마케팅이 콘텐츠 제작까지 함 (역할 침범)
- 크리에이티브가 전략 없이 콘텐츠 만듦 (방향 부재)

## 유튜브 우선 근거

- 검색 의도 명확 (구매 직전 행동)
- 콘텐츠 수명 길음 (1년+ 검색 트래픽)
- 크로스 플랫폼 재가공 효율 (롱폼 → 쇼츠 → 릴스 → 블로그 → 스레드)
- 홈리빙 카테고리에서 자체 상품 보유 채널 부족 → 차별화 기회

## 인스타그램 전략

- 릴스: 트렌드 음악·해시태그 활용
- 피드: 라이프스타일 무드 일관성
- 캐러셀: 정보 전달 + 스와이프 유도

## 블로그 전략

- SEO 키워드 + 제품 정보 + 라이프스타일
- 네이버 블로그 vs 자사 블로그 구분
- 스마트스토어 연동

## 스레드 전략

- 짧은 텍스트 (트렌드·일상·제품 스토리)
- 대화 유도
- 빠른 반응

## 좋은 예 (STEP 2.0 전체)

```
Q1. 오늘의집 기획전 + 유튜브 숏폼 집중 — 이유: 오늘의집 기획전 매출 기여도 40%,
유튜브 '주방 정리' 키워드 월 검색 12만, 홈리빙 채널 상위 10개 중 자체 상품 보유 채널 2개뿐.

Q2. 광고 60% + 콘텐츠 40% — 이유: 광고 CAC 8,000원, 유튜브 숏폼 CAC 추정 3,000원.
콘텐츠 비중을 40%까지 올려 6개월 후 유기 유입 30% 달성 목표.

Q4. 유튜브 → 인스타 순서 — 유튜브 숏폼 CPV가 인스타 릴스 대비 40% 저렴.
인스타는 유튜브 콘텐츠 재가공으로 추가 비용 최소화.

Q5. 크리에이티브에게 주간 2개 숏폼(주방 정리 꿀팁) + 1개 인스타 캐러셀 요청.
```

## 금지 표현

- "SNS도 강화합시다" (어떤 SNS? 왜? 구체성 없음)
- "콘텐츠를 좀 만들어요" (플랫폼·주제·빈도·타겟 없음)
