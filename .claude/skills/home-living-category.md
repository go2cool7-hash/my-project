# home-living-category

> 이 스킬은 가구/인테리어 카테고리의 시장 특성과 운영 노하우를 정리한 도메인 지식이다.

## 가구/인테리어 이커머스 특성

- **고관여 상품**: 객단가 높아 전환율 낮은 게 정상 (1~3%)
- **시즌성**: 이사철(봄/가을) 매출 집중, 비수기(여름/겨울) 대응 필수
- **비주얼 의존도**: 상세페이지·이미지 품질이 전환율에 직접 영향
- **배송 이슈**: 대형 가구 배송비·설치비가 마진에 영향. 반품 비용 20~30%.
- **리뷰 파워**: 구매 전 리뷰 의존도 매우 높음
- **홈리빙 현실**: 획기적인 상품이 드물다 — 컨셉 승부가 더 중요

## 카테고리별 특성

- **수납·정리**: 검색량 안정, 경쟁 심함. 차별화 키워드 필수 (예: "미니멀", "호텔식")
- **조명**: 무드 사진이 전환의 핵심. 인스타·핀터레스트 트렌드 민감
- **침구·패브릭**: 시즌성 강함. 색상·소재 SEO
- **수납가구**: 사이즈 정보 정확성이 CS 직결. 색상 차이 클레임 빈번
- **욕실용품**: 습기·내구성·디자인의 트레이드오프. 항균·방습 소재 차별화

## 의사결정 경로

```
인지 → 관심 → 비교 → 구매 → 후기
```

각 단계별 장벽:
- 인지: SEO 키워드, 노출
- 관심: 첫 화면 후킹 (3초 룰)
- 비교: 가격, 리뷰, 사이즈 정보
- 구매: 배송비, 설치, 반품 정책
- 후기: 실물 일치도, 배송 만족도

## 시즌 캘린더

| 시기 | 매출 패턴 | 카테고리 포커스 |
|---|---|---|
| 2~4월 | 봄 이사철 피크 | 수납, 침구, 조명 |
| 5~7월 | 여름 비수기 | 시원한 소재(린넨, 라탄) |
| 8~10월 | 가을 이사철 피크 | 수납, 가구, 조명 |
| 11~1월 | 겨울 | 패브릭, 무드 조명, 홈데코 |

## 현재 상태 (메인홈 기준)

- 매출 월 1,500만 (전성기 7,000만 대비 78% 하락)
- SKU 331개 (신상 월 2~3개 추가 목표)
- 신상 개발이 매출 회복의 핵심
- 자비스 1.0은 실시간 시장 데이터 접근에 한계 (PB-9 전제)
