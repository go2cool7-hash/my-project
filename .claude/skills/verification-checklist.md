# verification-checklist

> 이 스킬은 산출물 품질 검증의 이중 렌즈 체크리스트 도메인 지식이다.

## 이중 렌즈

- **망원경 🔭**: "숲이 제대로 조성되어 있는가?" — 구조적 결함 사전 차단
- **현미경 🔬**: "나무가 병들지 않았는가?" — 데이터 품질·논리 무결성 정밀 검증

## 모드 결정

- 입력이 기획서·전략·구조 설계·로드맵 → 망원경
- 입력이 산출물·데이터·결과물·실행 프롬프트 → 현미경
- 판별 불가 → "구조 관점? 품질 관점?" 확인

## 망원경 모드 — T1~T6 (구조 검증)

**목적**: 기획서 뼈대가 탄탄하고 유연한가? (경량, 내용 품질은 보지 않음)

- **T1 MECE**: 범위 분류가 중복·누락 없이 완전한가?
- **T2 계층 구조**: 상위·하위 위계가 논리적인가?
- **T3 논리적 비약**: A→B 흐름이 끊기지 않는가? 중간 단계 누락 없는가?
- **T4 확장성**: 새 요소 추가 시 구조 갈아엎지 않고 수용 가능한가?
- **T5 모듈화**: 특정 파트 수정해도 전체가 마비되지 않는가?
- **T6 목적 부합성**: 전체가 최종 목표를 향해 일관 정렬되어 있는가?

**FAIL 심각도**: 높음 / 중간 / 낮음

**판정**: pass (FAIL 0 또는 전부 낮음) / reject (FAIL 1+ 중간 이상) / escalate

**반려 기준 제한**: "구조적 결함"만. "기존 틀 안 맞는다"는 반려 사유 아님.

## 현미경 모드 — M1~M10 (품질 검증)

**목적**: 개별 내용에 결함이나 군더더기가 없는가?

- **M1 누락**: 필수 정보·조건 빠짐
- **M2 충돌**: A vs B 규정 부딪힘
- **M3 모순**: 앞뒤 말 안 맞음
- **M4 오류**: 명백히 틀린 사실, 계산 실수
- **M5 오염**: 불필요 정보가 본질 흐림
- **M6 정합성**: 형식·규칙·규격 일관성
- **M7 중복**: 미세하게 다른 반복으로 혼동
- **M8 모호성**: "적절히/필요 시/충분히" — 행동 미특정
- **M9 타당성**: 이론적 OK, 현실 실행 가능?
- **M10 간섭**: 규칙 존재하지만 다른 규칙·흐름·예외 조합으로 트리거 경로 차단/우회
  - M2(직접 충돌)와 차이: M10은 경로 차단

## 전략 질문 Q1~Q4 (두 모드 공통)

표준 검증 이상에서 필수:

- **Q1 검증 집중점**: 가장 무너지기 쉬운 지점은? 가장 먼저 깊게 봤는가?
- **Q2 맹점 인식**: 놓치고 있을 수 있는 관점은?
- **Q3 연쇄 영향**: 발견된 문제가 다른 에이전트·문서에 미치는 영향은?
- **Q4 반려 vs 통과 판단**: 반려할 수준인가, 주의사항 기재 후 통과시킬 수준인가?

## LLM 실행 가능성 점검 (에이전트 프롬프트 검증 시)

- **① 행동 특정성**: "이 규칙을 읽은 Claude가 첫 번째 행동을 알 수 있는가?"
- **② 추상어 감지**: "파악/진단/점검/고려/강화/개선/확인/검토/분석" 단독 사용 시 FAIL 후보
- **③ 출력 검증 가능성**: 실행 여부를 출력에서 구분 가능한가?

발견 시: M8 심각도를 "높음"으로 상향.

## 종합 판단

**건강도 등급**:
- 견고함: FAIL 0개
- 보통: FAIL 1~2개 (중간 이하)
- 취약함: FAIL 1+ (높음) 또는 FAIL 3+ (중간)
- 위태로움: FAIL 3+ (높음)

**최종 판정**: pass / reject / escalate — 반드시 "근거:" 병기

## 분석 깊이 등급

- **빠른 점검**: T1+T3+T6 / M1+M3+M6 핵심 3개. 최대 500자.
- **표준 검증** [기본값]: 전체 + Q1~Q4. 최대 2000자.
- **정밀 감사**: 전체 + 적대적 시나리오 + LLM 실행 가능성 + 강점 사실 보고.

## 출력 포맷

```
[종합 판단]
모드: 🔭 망원경 / 🔬 현미경
검증 대상: [대상명]
건강도: [등급] — [맥락 해석 한 줄]
판정: [pass/reject/escalate] — 근거: [한 줄]
최중요 발견: [가장 먼저 다뤄야 할 1개]
시스템 영향: [영향 에이전트/문서]

[항목별 판정]
T1/M1: PASS/FAIL — [심각도] [한 줄 설명]
...

[전략 질문]
Q1 집중점: [답변]
Q2 맹점: [답변]
Q3 연쇄: [답변]
Q4 판단: [답변]

[검증 기반 제안] (해당 시)
검증 근거: [T?/M? — 발견 요약]
제안 트리거: IF [조건] THEN [행동]
영향 범위: [에이전트/문서]
제안 한계: [커버하지 못하는 것]
```

## 금지 표현

- 모호한 경고 ("리스크가 있습니다") → "[T?/M?]에서 [무엇]이 [조건]에서 실패합니다"
- 완곡/미화 ("조금 아쉬운") → "FAIL"
- 감정적 ("걱정됩니다") → "심각도 높음"
- 근거 없는 제안 ("~하는 것이 좋겠다" 단독) → "검증 근거:" 병기 필수
- 긍정 평가 ("잘했다") → 사실 보고로 ("T 6개 중 5개 통과")
