# channel-registration

> 이 스킬은 4채널 등록 규격과 채널 전략 판단 도메인 지식이다.

## 채널별 등록 규격

### 오늘의집
- 대표이미지: 정사각형 (800×800px+)
- 독자 카테고리 트리 (예: 거실가구 > 사이드테이블)
- 수수료 12~20%
- 시공사례·집들이 태그 포함 필수
- 리뷰 설정, 리뷰 답글 자동화 가능
- 기획전 매출 기여도 40%

### 스마트스토어
- SEO 키워드 상품명 (네이버 검색 알고리즘 최적화)
- 네이버 카탈로그 연동 (속성 정밀 입력)
- 수수료 ~5.5%
- 검색 노출까지 3일 선반영 → **선등록 채널**
- 블로그 연동 구조

### 쿠팡
- 로켓그로스 / 마켓플레이스 / 로켓배송 구분
- 아이템위너 경쟁 확인 (같은 상품 여러 판매자 중 1명 대표 노출)
- 수수료 ~10.8%
- 누끼 이미지 + 기능·스펙·가격 먼저
- A+ 콘텐츠 활용

### 29CM
- 프리미엄 톤 확인
- 수수료 ~25%
- 에디토리얼 이미지 + 스토리텔링 카피
- 브랜드 스토리 강조
- 객단가 전략 (높은 가격대)

## 채널 전략 질문 (STEP 2.5)

등록 작업 진입 시 반드시 4개 질문에 구체적 근거 답변:

- **Q1. 채널 우선순위**: 4채널 중 먼저 등록할 채널? 왜?
  - 상품 특성(가격대, 카테고리, 고객층)과 채널 특성 매칭
  - 좋은 예: "스마트스토어 선등록 — 이유: 검색 노출까지 3일 선반영 필요"

- **Q2. 가격 전략**: 채널별 가격 차이를 두는가? 근거?
  - 수수료율 차이 반영, 마진 가드레일, 경쟁 가격

- **Q3. 키워드·노출 전략**: 각 채널 검색 알고리즘에 맞춘 키워드?
  - 스마트스토어 SEO / 쿠팡 아이템위너 / 오늘의집 카테고리+시공사례 태그

- **Q4. 재고·물류 리스크**: 4채널 동시 운영 시 재고 충돌 위험? 대응?

## 작업 지시서 형식 (사람 실행자용)

```
체크리스트 형태 + 모든 수치/규격 명시 + 예외 대응

✅ 좋은 예:
"오늘의집 대표이미지:
 - 800×800px, JPG
 - 파일명 SKU-001-main.jpg
 - 카테고리: 거실가구>사이드테이블
 - 배송템플릿: 대형가구-설치배송
 - 키워드: 미니멀 사이드테이블, 우드 사이드테이블"

❌ 나쁜 예:
"이미지 올려주세요"
```

## 검색 알고리즘 최적화 포인트

- 스마트스토어: 키워드 매칭 정확도 + 카탈로그 연동 + 상품 속성 정밀
- 쿠팡: 아이템위너(가격 + 배송 + 평점) 경쟁
- 오늘의집: 카테고리 + 시공사례 태그 + 리뷰 수
- 29CM: 큐레이션 + 브랜드 가치

## 4채널 분화 원칙

**금지**: 4채널 복사+붙여넣기 ("4채널 동시 등록" 무전략 처리)

**필수**: 채널별 이미지·카피·키워드·가격 분화 — Q1~Q4 판단 근거 포함
