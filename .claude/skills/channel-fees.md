# channel-fees

> 이 스킬은 4채널 수수료·정산 구조 도메인 지식이다. 상품MD 마진 시뮬레이션, 커머스옵스 가격 세팅, 데이터분석 ROAS 계산에 공통 적용.

## 채널별 수수료 구조

| 채널 | 수수료 | 정산 주기 | 특이사항 |
|---|---|---|---|
| 오늘의집 | 12~20% | 약 30일 | 기획전 매출 영향 큼, 카테고리별 수수료 차이 |
| 29CM | ~25% | 약 30~45일 | 객단가 높음, 프리미엄 톤 |
| 쿠팡 | ~10.8% | 약 15~30일 | 로켓그로스/마켓플레이스 구분, 아이템위너 경쟁 |
| 스마트스토어 | ~5.5% | 약 15일 | SEO 핵심, 네이버 카탈로그 연동 |

## 마진 계산 공식

```
판매가 (P)
− 원가 (C)
− 채널 수수료 (P × 수수료율)
− 부가세 (P × 10/110)
− 물류비 (대형 가구는 5,000~15,000원)
− 반품률 충당 (대형 가구 약 5~10%)
= 실제 마진
```

## 부대비용 체크리스트

- ✅ 채널 수수료
- ✅ PG 수수료 (해당 시)
- ✅ 부가세
- ✅ 물류비 (출고 + 반품)
- ✅ 설치비 (대형 가구)
- ✅ 광고비 (별도 계상)
- ✅ 정산 주기로 인한 현금 흐름 영향

## 가격 동일 설정 시 마진 시뮬레이션 (필수)

같은 판매가라도 채널별 마진은 다음과 같이 다름:

```
예: 판매가 29,000원, 원가 8,000원, 배송 5,000원, 반품 충당 5%

오늘의집 (수수료 15%):
  29,000 − 4,350(수수료) − 2,636(부가세) − 5,000(배송) − 1,450(반품) − 8,000(원가) = 7,564원 (26.1%)

29CM (수수료 25%):
  29,000 − 7,250 − 2,636 − 5,000 − 1,450 − 8,000 = 4,664원 (16.1%)

쿠팡 (수수료 10.8%):
  29,000 − 3,132 − 2,636 − 5,000 − 1,450 − 8,000 = 8,782원 (30.3%)

스마트스토어 (수수료 5.5%):
  29,000 − 1,595 − 2,636 − 5,000 − 1,450 − 8,000 = 10,319원 (35.6%)
```

→ 채널별 동일 가격 + 수수료율 차이 5%p+ 시 경고 (마진 시뮬레이션 필수)

## BEP 역산

```
BEP 판매량 = 고정비 / (개당 마진)

예: 신상 개발비 200만원 고정비 가정
오늘의집 마진 7,564원 → BEP 약 265개
스마트스토어 마진 10,319원 → BEP 약 194개
```

## ROAS 연쇄 계산

```
ROAS = 광고 매출 / 광고비
손익분기 ROAS = 100% / 마진율

예: 마진율 30% → 손익분기 ROAS = 333%
실제 ROAS가 손익분기 미만이면 광고 손실
```
