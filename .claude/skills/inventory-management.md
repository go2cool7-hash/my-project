# inventory-management

> 이 스킬은 재고 관리·발주·입출고 도메인 지식이다.

## 재고 시스템 (Cello)

자비스는 Cello를 재고 마스터로 사용. 4채널 재고는 Cello를 통해 동기화.

## 안전재고 계산

```
안전재고 = 일평균 판매량 × 리드타임 × 안전 계수(보통 1.5)

예: 일평균 3개 판매, 리드타임 14일, 계수 1.5
   → 안전재고 = 3 × 14 × 1.5 = 63개
```

## 발주 시점 역산

```
발주 시점 = 현재 재고가 (안전재고 + 리드타임 × 일평균 판매) 이하로 떨어지는 시점

예: 안전재고 63개 + 리드타임 14일 × 일평균 3개 = 105개 도달 시 발주
```

## 4채널 재고 분배 원칙

- 채널별 판매 속도 기반 분배
- 품절은 과잉재고보다 위험 (CS + 평점 하락) — 안전재고 확보 우선
- Cello ≠ 채널 재고 불일치 시 즉시 동기화

## 발주서 필수 항목

```
- 품목 (SKU 단위)
- 수량
- 단가
- 납기일
- 배송지
- MOQ (최소 주문 수량)
- 결제 조건
```

## 입고 체크리스트

- ✅ 입고 수량 vs 발주 수량 대조
- ✅ 실물 검수 (불량률 확인)
- ✅ 재고 시스템 등록
- ✅ 채널별 재고 분배 업데이트

## 출고 SOP

```
주문 접수 → 재고 차감 → 출고 처리 → 송장 발급 → 배송 추적
```

대형 가구 설치배송:
- 일정 조율 필요 (택배 ≠ 설치)
- 고객과 사전 일정 확정
- 설치 완료 사진 확보

## 품절 발생 시

```
1. 즉시 해당 채널 일시 중지 처리 (지시서)
2. 대표님 알림
3. 발주 검토 요청
4. 채널별 재고 재분배 검토
```

## 재고 이상 진단 패턴

- P1: 특정 SKU 품절 반복 + 발주 정상 → 안전재고 계산 오류 or 4채널 분배 로직 문제
- P2: Cello 재고 ≠ 채널 재고 → 동기화 누락 or 시스템 이슈
