# market-research

> 이 스킬은 시장 리서치 방법론 도메인 지식이다.

## 리서치 영역

- 카테고리 동향 (전체 시장 성장/축소)
- 경쟁사 분석 (가격·리뷰·포지셔닝)
- 기회 포인트 (시장 빈틈, 새 트렌드)
- 셀러·고객 페인포인트
- 채널별 추세

## 트렌드 식별 방법

### 약한 신호(weak signal)에서 트렌드 포착
- 검색 키워드 추이 (네이버 데이터랩, 구글 트렌드)
- SNS 해시태그 빈도
- 커뮤니티 토픽
- 인플루언서 콘텐츠
- 경쟁사 신상 출시

### 수명 주기 판단

- **마이크로 트렌드**: 3~6개월 (빠른 진입·빠른 회수)
- **매크로 트렌드**: 1년+ (안정적이지만 경쟁 격화)
- **일시적 유행**: 1~2개월 (진입 자체가 리스크)

### 확산 곡선 (Rogers)

```
이노베이터 → 얼리어답터 → 초기다수 → 후기다수 → 지각수용

진입 타이밍 판단: "지금 곡선의 어디인가?"
- 이노베이터: 너무 이름, 시장 형성 안 됨
- 얼리어답터: 좋은 타이밍, 차별화 가능
- 초기다수: 본격 성장, 경쟁 격화 시작
- 후기다수: 가격 경쟁
- 지각수용: 진입 비추천
```

## 경쟁사 분석 체크리스트

- 가격대·할인율 추이
- 리뷰 수·평점·주요 클레임
- 포지셔닝 (어떤 가치를 주장)
- 베스트셀러 변동
- 마진 역산 ("저 가격엔 이 마진이 나오는가")
- 멀티채널 운영 패턴
- 마케팅 채널·콘텐츠 전략

## 고객 불만 분석 (갈래 1 연결)

경쟁사 리뷰에서 "해결되지 않은 불편" 추출:

```
예: 오늘의집 '욕실 수납' 리뷰 500개 분석
→ "습기로 곰팡이 핀다" 불만 23% (최다)
→ 항균·방습 소재 수납함 시장 빈틈 발견
```

- 기존 도구 가격대·기능·강약점
- 셀러 핵심 페인포인트
- 자비스 SaaS 차별점

## 시장 데이터 한계 인식 (PB-9)

자비스 1.0은 실시간 시장 데이터 접근에 한계. 그래서:
- 데이터 부족 시에도 가설을 세움 + 신뢰도 명시
- 통찰·아이디어로 보완 ("데이터는 부족하지만, 이 시장 구조를 보면...")
- "데이터 부족해서 일반론밖에" → 변명
