# ad-operations

> 이 스킬은 광고 집행·관리·최적화 도메인 지식이다.

## 광고 범위

- 네이버 SA(검색광고) / DA(디스플레이)
- 메타(인스타그램) 광고
- 오늘의집 광고
- 유튜브 광고 (해당 시)

## 자율 영역 vs 승인 필요

**자율 영역** (집행 후 결과 기록 → 주간 보고):
- 입찰가 ±20%
- 키워드 추가/제거
- 소액 최적화

**승인 필요**:
- 예산 증액 → 대표님 승인
- 신규 채널 집행 → 대표님 + 디렉터 승인

## 광고 최적화 우선순위

```
예산 재배분 > 키워드 조정 > 크리에이티브 변경 > 비딩 조정 >> 캠페인 중지
```

**원칙**: 최적화는 "끄기"가 아니라 "더 잘 쓰기" (OB-3).

## 소액 캠페인 판단

- 일예산 5,000원 이하 → 7일 누적으로 판단 (일일 데이터 불안정)
- 일예산 5,000원 초과 → 일/주 단위 판단 가능

## ROAS·CPA 분석

```
ROAS (광고비 대비 매출 비율)
= 광고 매출 / 광고비 × 100%

손익분기 ROAS = 100% / 마진율
예: 마진율 30% → 손익분기 ROAS = 333%

CPA (광고비 대비 전환 비용)
= 광고비 / 전환수
```

## 어트리뷰션 모델

- 라스트 클릭 vs 멀티 터치
- 채널 간 측정 기준 통일 중요
- 마케팅 자체 평가 vs 데이터분석 독립 검증 불일치 시 측정 기준 차이 먼저 확인

## 극단적 제안 차단 (PB-4)

```
"전부 중지", "예산 3배" 같은 극단적 제안은
극단적 데이터 근거(30일 전환 0건 등) 있을 때만 허용.

대신 단계적 액션:
- 입찰가 -20%
- 저성과 키워드 제거
- 크리에이티브 A/B 테스트
```

## 광고 성과 진단 패턴

| 신호 | 진단 |
|---|---|
| ROAS↓ + CTR 정상 | 전환율 문제 → 상세페이지 점검 |
| ROAS↓ + CTR↓ | 크리에이티브 문제 → 소재 교체 |
| ROAS↓ + 노출↓ | 입찰 경쟁 패배 → 입찰가 검토 |
| CPA↑ + 전환수 유지 | 시장 경쟁 격화 → 채널 다변화 |

## 채널별 광고 특성

| 채널 | 특성 |
|---|---|
| 네이버 SA | 검색 의도 명확, 전환율 높음, 키워드 경쟁 |
| 네이버 DA | 노출 중심, 브랜드 인지 |
| 메타 | 타겟팅 정밀, 시각 의존 |
| 오늘의집 | 인테리어 관심층, 카테고리 노출 |
| 유튜브 | 영상 소재, 인지 + 전환 |

## 캠페인 보고 형식

```
캠페인명 / 기간 / 예산 / 매출 / ROAS / CPA / 전환수
+ 원인 진단 (지표 뒤의 이유)
+ 2차 결과 예측 (제안 시)
+ 단계적 액션 제안
```
