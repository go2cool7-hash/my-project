# market-landscape

> 이 스킬은 플래너의 시장 거시 환경 파악 도메인 지식이다.

## 메인홈 현재 위치

- 매출: 월 1,500만 (전성기 7,000만 대비 78% 하락)
- SKU: 331개
- 신상 추가: 월 2~3개 목표
- 12개월 내 매출 목표: 월 7,000만

## 4채널 시장 환경

| 채널 | 주요 고객층 | 우리의 강점 후보 | 우리의 약점 후보 |
|---|---|---|---|
| 오늘의집 | 인테리어 관심 2030 | 자체 상품 보유 / 콘텐츠 가능 | 기획전 의존도 |
| 29CM | 프리미엄·감성 | 디자인·스토리텔링 | 객단가 |
| 쿠팡 | 가격·배송속도 | - | 가격 경쟁력 |
| 스마트스토어 | 검색 의도 명확 | SEO 콘텐츠 가능 | 수수료는 낮으나 검색 경쟁 |

| 플랫폼 | 검색량/특성 | 진입 기회 |
|---|---|---|
| 유튜브 ⭐ | 검색 의도 명확, 수명 길음 | 홈리빙 자체 상품 보유 채널 상위 10개 중 2개뿐 → 차별화 기회 |
| 인스타그램 | 시각 의존 | 라이프스타일 무드 |
| 블로그 | SEO | 스마트스토어 연동 |
| 스레드 | 빠른 반응 | 트렌드·일상 |

## 사업 흐름 파악 체크리스트

플래너가 매 기획 전 점검:

- 현재 매출 추이 (전월/전분기/전년 대비)
- 채널 의존도 (한 채널 80% 이상이면 리스크)
- 신상 비율 (신상이 매출 회복 핵심)
- 시즌 위치 (이사철 피크 vs 비수기)
- 경쟁 환경 (신규 진입자, 가격 변동)

## 외부 리서치 디폴트

플래너는 모든 산출물에 외부 시각 디폴트:
- 시장 흐름
- 경쟁 동향
- 기술 변화 (AI 트렌드 — 빌더와 연계)

데이터 기반 (있으면) + 통찰 기반 (데이터 부족 시) 양쪽 활용.

## 사업 구조 (3대 기둥)

```
🛒 쇼핑몰 (메인홈) — 현재 매출 엔진
🤖 자비스 — AI 멀티에이전트 시스템 (쇼핑몰을 첫 고객으로)
💰 수익화 — SaaS 전환 (자비스를 다른 셀러에게)
```

원칙: 모든 작업이 3대 기둥 중 어디에 걸리는지 명시.
